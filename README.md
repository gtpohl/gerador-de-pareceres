# Parecer de Retenção · Modelo 2026

Esta cópia inclui o código do site, o modelo Word de 2026, o cabeçalho em PDF, o logotipo e as bibliotecas locais. A importação das planilhas e a geração dos pareceres em Word e PDF acontecem no navegador.

## GitHub Pages

1. Extraia este ZIP. Envie os arquivos extraídos à raiz de um novo repositório, com o index.html e os demais arquivos lado a lado. Inclua o .nojekyll se estiver visível.
2. Abra **Settings → Pages**. Escolha **Deploy from a branch**, **main** e **/(root)**. Salve.
3. Abra o endereço exibido em **Settings → Pages** após a publicação.
